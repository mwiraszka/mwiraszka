# Hi, I'm Michal

I'm a full-stack software engineer, passionate about designing and building scalable, elegant architectures for mobile and web.

I run [Eagami](https://eagami.com), an independent web design and development studio. I also maintain [Eagami UI](https://eagami.com/ui), the open-source Angular component library every Eagami site is built on.

**Eagami in the wild:**

- [Wawa Social](https://wawasocial.com) — Hosts a variety of social events in Warsaw, including singles nights, board game nights, and mixers for expats
- [London Chess](https://londonchess.ca) — A hub for the London Chess Club and chess events in London, ON
- [CIRC Aesthetics](https://circaesthetics.ca) — Cosmetic Interventional Radiology Clinic based in London, ON
- [Chordbomb](https://chordbomb.com) — Identifies the song playing around you and works out its chord progression
- [Brewski Bets](https://brewskibets.com) — A tracker for casual bets between friends, settled in beer
- [BeacBeac](https://beacbeac.com) — Attaches accessible stories to physical places, reaching visitors' phones as they approach
